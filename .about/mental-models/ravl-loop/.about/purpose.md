# Purpose of the `ravl-loop` mental model

This is the ontology of a loop for the whole `ravl` repository: what a loop is, its
parts, their relations, and the decision framework a loop reasons with. Every other
document in the repository — principles, decisions, code, tests — is judged against it.

It is read by anyone who writes a loop, reads a loop's learnings, contributes to the
library, or is an agent asked to reason about any of those. If the model and the code
disagree, the model wins and the code is fixed.
